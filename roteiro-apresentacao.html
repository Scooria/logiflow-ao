Perguntas prováveis

"Isto já está ligado a um banco ou à AGT de verdade?"

A integração EMIS/Multicaixa é código real, pronto para produção — falta apenas o contrato comercial com um banco (BFA/BAI/BIC) para obter a Entidade e as chaves de API. O RUPE (AGT) ainda não tem integração — está documentado como o próximo passo, porque exige credenciação junto da AGT.

"É só um mockup ou já funciona a sério?"

A app está a correr em modo demonstração com dados de exemplo, mas todo o backend (API, base de dados, autenticação) já está escrito e pronto — basta apontar a variável de ligação à API para sair do modo demo. Isso está documentado passo a passo no guia de deployment.

"Quanto tempo até ter isto em produção real?"

A infraestrutura (Docker, base de dados, hosting) está configurada e pronta a publicar num serviço como o Render em poucas horas. O que determina o calendário real é obter as credenciais institucionais (banco para o Multicaixa, AGT para o RUPE), não o desenvolvimento do software.
